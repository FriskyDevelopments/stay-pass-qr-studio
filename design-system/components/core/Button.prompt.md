Sharp-edged action button: primary is a Beacon fill with Ink text, secondary an accent outline; sharp corners always (radius 0).
```jsx
<Button variant="primary" onClick={go}>Create credential</Button>
<Button variant="secondary">Copy link</Button>
```
Variants: primary, secondary, ghost (hairline), danger (coral outline — revocation actions). Sizes sm/md/lg; md+ meet the 44px touch minimum.
