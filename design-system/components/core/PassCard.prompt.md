The credential card: flat Ink surface, hairline border, 6px tornasol holo strip on top (like a hologram on a physical pass), compact Signed Stroke mark.
```jsx
<PassCard passId="PASS 09-472" state="valid" expires="expires 18:00" />
```
State colors the meta line: valid mint, expiring amber, revoked coral. Set holo={false} for quiet lists.
