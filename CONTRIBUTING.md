# Contributing

Stay Pass QR Studio is a small, non-commercial MIT project.

1. Be kind. Read the [Code of Conduct](CODE_OF_CONDUCT.md).
2. Keep the guest path simple. Technical controls belong under Advanced settings.
3. Open Stay Pass is the default house-neutral rail. HostCasa and Folios are adapters, not the product.
4. Do not add commercial upsells, paid hosting, or closed credential issuance here.

Issues and pull requests are welcome on this repository and on the parent project [open-stay-pass](https://github.com/FriskyDevelopments/open-stay-pass).
